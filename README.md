# 🎓 Student Management System (Bash Script)

A simple Command-Line based Student Management System built using **Bash scripting**.

This project demonstrates file handling, input validation, logging, backup management, and menu-driven program structure in Linux.

---

## 🚀 Features

- ✅ Add Student
- 🔍 Search Student (By Roll, Name, Class)
- 📋 View All Students (Formatted Table Output)
- ❌ Remove Student (With Confirmation)
- 🛡 Automatic Backup Before Delete
- 📝 Logging System (logs.txt)
- 🎨 Colored Terminal Output
- 🔢 Input Validation (Numeric Checks)
